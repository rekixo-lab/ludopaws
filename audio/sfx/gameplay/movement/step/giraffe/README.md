# Giraffe hoof landings

Replace `lp_sfx_step_giraffe_01.wav` in this folder with the first take. The `_02.wav` and `_03.wav` slots are optional variations. Empty slots are omitted from the APK.

> One light giraffe hoof landing on a polished wooden game board. A soft wooden tick with a tiny rounded thud and a short natural decay. One isolated contact, close and dry. No gallop, jump take-off, animal voice, music, ambience or reverb.

Trim to roughly 40–75 ms and export as mono 16-bit PCM WAV at 44.1 or 48 kHz. The game uses its shared jump sound at take-off.
