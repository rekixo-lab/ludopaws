Account and data deletion

This page lets you request deletion of your Ludo Paws account and associated account data. For a Google-linked account, use the same Google identity that you previously linked. This does not delete your Google account or Google's separate Google Play order history.

For security, this page only asks the Ludo Paws server to delete an account after Google identity verification and an additional explicit confirmation. Session tokens are kept in page memory only and are not saved to browser storage.

When the request completes, the server removes the account profile, active sessions, wallet and gems, cosmetic inventory and rewarded-ad progress, account-linked app purchase ledger records, linked Friend ID and social records, and linked leaderboard profile. The app also attempts to clear its local profile, wallet, pending-purchase, friend and leaderboard caches. If the app reports that local cleanup failed, clear the app's storage on that device.

No separate long-term match-proof archive is created by the current online protocol. Match room records follow scheduled activity-based cleanup. Minimal hashed or pseudonymous security markers may remain as described in the Privacy Policy. Google Play's separate order history is not deleted.

Guest-only account (including after uninstall)

Before uninstalling, open Profile → Guest deletion code (for uninstall) in the app and save the code somewhere private. This separate code can delete an unlinked guest account only; it cannot sign in, recover the account, or access its data. To revoke a saved code, use Profile → Replace guest deletion code before uninstalling; replacing it invalidates all previously saved codes. If your guest account was linked to Google, use the Google sign-in section above instead.

Enter the code only on this official Ludo Paws deletion page. Do not email it or send it to support.

Enter your saved guest deletion code to continue.

Accounts without a saved guest code or sign-in problems

If you still have the app, you can also use Profile → Delete account and data. If you uninstalled without saving a guest deletion code, contact publisher support using the contact link below so the publisher can verify ownership through a separate process. Do not send passwords, session tokens, guest deletion codes, purchase tokens, or full payment details.

If you cannot complete deletion, email AI@rekixo.com. Support will verify account ownership through a reasonable process. Do not send passwords, access or refresh tokens, purchase tokens, full payment details, or guest deletion codes.

Contact publisher support for a deletion request

Read the Privacy Policy for full details of data use, sharing and retention. Deleting an account does not delete every offline copy on your device or records retained independently by Google or another service provider.

Never share your Google password or verification code. Ludo Paws will not ask for either.
